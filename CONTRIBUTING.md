# Contributing

Thanks for your interest in improving this take-home repository.

## Scope

This repository is a solution write-up and reference architecture, not a production codebase.

## How to contribute

- Open an issue describing the change and rationale.
- Keep edits focused and easy to review.
- Prefer clear language over heavy jargon.
- If adding architecture choices, include trade-offs.

## Pull request checklist

- Explain what changed and why.
- Keep diagrams and docs in sync.
- Preserve startup-cost awareness and operational realism.
